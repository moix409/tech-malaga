# Tech Málaga

Agenda web estática de demostración para descubrir eventos tecnológicos en Málaga. La interfaz incluye filtros por categoría, un calendario mensual interactivo y tema oscuro/claro.

## Abrir la web

Abre `index.html` directamente en un navegador moderno. No requiere dependencias, instalación ni proceso de compilación. También se puede servir esta carpeta con cualquier servidor estático.

## Datos de demostración

Los cinco eventos, sus fechas y ubicaciones son contenido ficticio para mostrar el funcionamiento de la interfaz. No son convocatorias confirmadas y sus enlaces de inscripción muestran un aviso; no existe registro real.

## Tema

La página usa inicialmente la preferencia del sistema operativo y guarda en el navegador la elección manual de tema.
